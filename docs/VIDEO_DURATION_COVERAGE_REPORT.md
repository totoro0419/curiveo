## データと再現方法

- `durations.json`: 全2,322 IDの証拠、保存秒数、source/sourceUrl/sourceVideoId、verifiedAt、status、競合。元の証拠を保持。
- `duration-audit.json`: 全IDと教科、単元、講座、タイトル、出典、欠損・検証状況を突合。
- `duration-group-audit.json`: 実際のアプリの階層・講座アウトライン・ルートを読み、1,791グループについて動画ID一覧・個別秒数・合計秒数・時分秒・欠損を記録。未検証を含む `verifiedTotalSeconds` はnull。
- 本番は秒数インデックスと状態インデックスのみを読み、監査JSONをバンドルしない。`history-duration-supplement.json` は移行証拠として残すが実行時に読み込まない。
- `npm run durations:audit`: ネットワークなしで監査再生成。
- `npm run durations:collect`: 実行環境の秘密変数 `YOUTUBE_API_KEY` で取得。キーをコマンド、VITE変数、Git、PR、ログに書かない。新規契約・課金設定は作成しない。
- 一度に1リクエスト、50件以下、ロックで同一チェックアウトの競合防止、各バッチの原子的保存、認証/通信/制限エラーでは停止し既存値を保持。APIが省略したIDを勝手に非公開・削除と断定せず `unavailable_unspecified` と記録。ライブ全長未確定は別状態。
- 公式値が保存値と異なると候補・差分を保存して `review_required` にする。上書きせず、次回レビューが必要。検証済みで更新期限内のIDは再リクエストしない。
- `npm run durations:test`: 収集処理の単体テストとID・集計・状態の検証。
- `npm run durations:complete`: 全件が有効期限内で正式再確認済みでない場合は失敗。PR CIにも独立の失敗ゲートを追加。

## 集計

グループの動画IDを重複排除し、正の整数秒を加算して最後に時分秒へ変換。欠損は合計に0秒として確定登録しない。未検証または欠損を含む画面は「記録済み」と未確認本数を表示し、確定「合計」と呼ばない。端末記録はメタデータがないときだけ参照し、0・小数秒・負値は拒否する。
